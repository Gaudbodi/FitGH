# Vision golden set — Phase 7 deliverable

`test_golden_vision.py` + `manifest.json` + `photos/` ship the 10-entry
Ghana-dish golden set per Phase 7 Plan 07 task P7-D.2.

## Usage

```bash
# Default — pytest collects but SKIPs (RUN_GOLDEN_SET unset).
pytest backend/tests/golden_set/

# Deterministic-fake mode (no Anthropic spend, MAPE = 0 % by construction).
RUN_GOLDEN_SET=1 pytest backend/tests/golden_set/ -v -s

# Real-Anthropic mode (operator pass — see LAUNCH.md §5).
RUN_GOLDEN_SET=1 GOLDEN_SET_REAL=1 ANTHROPIC_API_KEY=sk-… pytest backend/tests/golden_set/ -v -s
# Expected cost ≈ $0.005/photo × 10 = $0.05 for v1.0 placeholder photos.
# Real Ghana-food photography in v1.1 raises this to ~$0.15 at 30 photos.
```

## v1.0 status

- 10 manifest entries spanning the 25-dish catalogue (jollof, banku,
  waakye, fufu, kelewele, red-red, kontomire, omotuo/fufu, tuo zaafi, kenkey).
- 10 placeholder JPEGs (64×64 solid-colour, generated by Pillow). Each
  manifest entry's `source: "placeholder"` field flags this for the v1.1
  operator pass.
- Harness runs cleanly in deterministic-fake mode (MAPE = 0 % by
  construction). The shape is validated; the model accuracy is the
  operator's real-Anthropic pass.

## Re-run triggers

Re-run the real-Anthropic golden set on:

- Any bump of `LLM_VISION_MODEL` in env / `app/config.py`.
- Any change to `MODEL_PRICING_PER_1K` in `app/lib/vision.py` (price bumps
  usually coincide with model rev releases).
- Any non-trivial change to `build_system_prompt` in `app/lib/vision.py`
  (the cached block hash shifts; re-prove accuracy stays in bounds).

## CI policy

`@pytest.mark.skipif(os.environ.get("RUN_GOLDEN_SET") != "1", …)` keeps the
harness out of CI by default. The operator runs it locally for the triggers
above and post-launch on a regular cadence (LAUNCH.md §5).

## Targets

- MAPE < 25 % on the env-pinned model (`claude-sonnet-4-6`).
- Dish-name accuracy ≥ 70 % (difflib fuzzy match, ratio ≥ 0.7).

Per CONTEXT.md these are documented targets, not phase blockers. Real-
Anthropic failures should be triaged operator-side rather than failing
deploys.
